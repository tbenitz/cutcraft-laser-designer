CutCraft

Laser SVG studio for outlined text, image tracing, holding bridges, and material fallout preview.

Repository: tbenitz/cutcraft-laser-designer

The full single-file app is CutCraft_Laser_Designer.html. Open that file in a browser to run it locally — no build step.

  1. Open the repo and choose Add file → Upload files
  2. Drop CutCraft_Laser_Designer.html
  3. Optional: rename it to app.html and turn on GitHub Pages from main
